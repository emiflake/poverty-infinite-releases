# Poverty Infinite

A Torchlight Infinite loot and currency tracker for Windows.

## Download

**[Download v0.1.8 for Windows](https://raw.githubusercontent.com/emiflake/poverty-infinite-releases/main/PovertyInfinite_0.1.8_x64-setup.exe)**

Run the installer; no admin rights needed. The app updates itself when new
versions are published here.

---

This repository only hosts release builds and the auto-update feed
(`latest.json`). It is replaced on every release.
